# Reading Workflow

## Purpose

This document defines the standard workflow for reading and managing books within the **Books** repository. Its goal is to transform a personal library into a structured, long-term learning system.

---

## Reading Process

1. Acquire the book.
2. Place it in the appropriate library category.
3. Record it in the reading status tracker.
4. Read with a clear objective.
5. Highlight important ideas.
6. Create or update notes in the appropriate repository when required.
7. Review key insights after completion.

---

## Reading Status

Suggested stages:

- To Read
- Currently Reading
- Completed
- Revisit
- Reference Only

---

## Repository Responsibilities

- **Books** stores the original PDF and reading status.
- **Foundation** stores reusable knowledge, methodologies, and book notes.
- **India** stores research derived from relevant historical and documentary sources.

---

## Guiding Principles

- Read with intention.
- Prefer understanding over speed.
- Avoid duplicate notes.
- Keep source material separate from derived knowledge.
- Revisit high-value books periodically.

---

## Status

This workflow will evolve as the Personal Knowledge Ecosystem grows and reading habits mature.
