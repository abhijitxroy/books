# India Books

This directory contains books related to India as a whole.

Unlike state-specific collections, these books cover India from a national or pan-Indian perspective and are not currently assigned to any individual state.

## Scope

Examples include:

- Ancient India
- Medieval India
- British India
- Economic History
- Political History
- Freedom Movement
- Constitutional History
- Cultural History
- Pan-India Reference Works

## Organization

At present, all India-level books are stored directly under this directory.

As the collection grows, books may later be reorganized into dedicated categories such as:

- ancient-history/
- medieval-history/
- colonial-history/
- freedom-movement/
- economy/
- politics/
- biographies/
- reference/

## Relationship to State Collections

State-specific books are maintained separately under:

```
states/<state>/...
```

For example:

```
states/west-bengal/
states/maharashtra/
states/tamil-nadu/
```

This separation keeps national history independent from regional collections while allowing future cross-references between them.

## Naming Convention

Books in this directory use the following identifier format:

```
IND-<LANG>-<NUMBER>
```

Examples:

- IND-EN-001
- IND-EN-002
- IND-BN-001

Identifiers are permanent and should never be reused.

## Book Structure

Each book follows the standardized repository layout:

```
IND-EN-001 - Book Title/
├── IND-EN-001 - Book Title.pdf
└── IND-EN-001 - Book Title.summary.md
```

Additional research artifacts such as notes, timelines, references, and extracted metadata may be added in future phases.

## Status

Current focus:

- Acquire India-level reference books.
- Verify bibliographic metadata.
- Create summary files.
- Build the foundational India research library.

Future work includes categorization into dedicated subject directories once the collection grows sufficiently.

# India Books

This directory contains books related to India as a whole.

Unlike state-specific collections, these books cover India from a national or pan-Indian perspective and are not assigned to any individual state collection.

The goal is to build a comprehensive research library for Indian history that complements the individual state collections.

## Scope

This collection includes works covering topics such as:

- Ancient India
- Medieval India
- Early Modern India
- British India
- Economic History
- Political History
- Constitutional History
- Freedom Movement
- Military History
- Social History
- Cultural History
- Religious History
- Biographies
- Reference Works

## Organization

At present, all India-level books are stored directly under this directory.

This keeps the collection simple while the repository is still growing.

As the collection expands, books may later be reorganized into dedicated categories such as:

- ancient-history/
- medieval-history/
- colonial-history/
- freedom-movement/
- economy/
- politics/
- military-history/
- biographies/
- culture/
- religion/
- reference/

## Relationship to State Collections

National and state collections are maintained independently.

```
history/
└── india/
    ├── books/
    └── states/
        ├── west-bengal/
        ├── maharashtra/
        ├── tamil-nadu/
        └── ...
```

State-specific books remain within their respective state collections, while books covering India as a whole remain here.

## Naming Convention

Every India-level book receives a permanent identifier.

```
IND-<LANG>-<NUMBER>
```

Examples:

- IND-EN-001
- IND-EN-002
- IND-BN-001

Identifiers are unique and are never reused.

## Standard Book Structure

Every managed book follows the same layout:

```
IND-EN-001 - Book Title/
├── IND-EN-001 - Book Title.pdf
└── IND-EN-001 - Book Title.summary.md
```

Future additions may include:

- notes.md
- timeline.md
- bibliography.md
- extracted-data/
- images/

## Research Workflow

1. Acquire the source.
2. Verify bibliographic metadata.
3. Assign a permanent Book ID.
4. Organize using the standard directory structure.
5. Create the summary file.
6. Extract historical knowledge.
7. Cross-reference people, places, events, timelines, and maps.

## Current Status

- Prepare the collection for future categorization.
