# Kolkata Research Notes

This directory contains personal reading and research notes for Kolkata-related books.

## Purpose

- Capture insights while reading.
- Record timelines, people, places, and events.
- Prepare material for future articles, presentations, and documentaries.
- Maintain a personal knowledge base instead of annotating PDFs.

## Naming Convention

```
KOL-BN-001.md
KOL-BN-005.md
KOL-EN-001.md
```

Each note corresponds to one book and is created only when reading begins.

## Workflow

1. Select a book from `books/`.
2. Copy `templates/BOOK-NOTES-TEMPLATE.md`.
3. Rename it using the Book ID.
4. Fill the notes while reading.
5. Update `MASTER-BOOKS.md` when the book is completed.

## Status

This folder remains empty until a book is actively being read.
