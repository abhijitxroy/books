# Kolkata Bibliography

A research-oriented bibliography supporting the documentary history of Kolkata. This directory contains the canonical catalogue, curated reading guides, acquisition trackers, verification records, and research workflows for books related to Kolkata.

## Objectives

- Build a comprehensive bibliography for Kolkata.
- Maintain a single canonical catalogue.
- Organize books by language and subject.
- Track acquisition, verification, and copyright status.
- Support documentary and historical research.

## Directory Structure

| File | Purpose |
|------|---------|
| `MASTER-BOOKS.md` | Canonical bibliography and master catalogue of all Kolkata-related books. |
| `BENGALI-BOOKS.md` | Curated guide to Bengali-language books. |
| `ENGLISH-BOOKS.md` | Curated guide to English-language books. |
| `VERIFICATION.md` | Bibliographic verification tracker. |
| `PUBLIC-DOMAIN.md` | Copyright and public-domain acquisition tracker. |
| `WANTED.md` | Acquisition and wishlist tracker. |
| `READING-ORDER.md` | Recommended historical reading roadmap. |
| `CANDIDATE-BOOKS.md` | Candidate books awaiting evaluation and inclusion. |

## Research Workflow

1. Identify candidate books.
2. Verify bibliographic metadata.
3. Add verified entries to `MASTER-BOOKS.md`.
4. Classify books by language and subject.
5. Record copyright and acquisition status.
6. Assign Book IDs after verification.
7. Integrate books into the recommended reading roadmap.

## Repository Philosophy

- `MASTER-BOOKS.md` is the single source of truth.
- Other bibliography files provide specialized views or workflows.
- Bibliographic metadata should never be duplicated unnecessarily.
- All research should remain verifiable and traceable.
