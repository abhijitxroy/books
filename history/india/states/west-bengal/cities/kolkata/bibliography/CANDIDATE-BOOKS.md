# Candidate Books

> This file contains books currently under evaluation before they are considered for inclusion in the `MASTER-BOOKS.md` bibliography.

## Purpose

- Track newly discovered books.
- Evaluate historical relevance.
- Avoid duplicate entries.
- Record evaluation decisions.

## Evaluation Workflow

1. Discover the title.
2. Verify bibliographic metadata.
3. Check whether it already exists in `MASTER-BOOKS.md`.
4. Assess historical relevance.
5. Decide whether to include, reject, or defer.
6. If accepted, add it to `MASTER-BOOKS.md` and classify it.

## Evaluation Criteria

- [ ] Bibliographic details verified
- [ ] Author verified
- [ ] Historical relevance confirmed
- [ ] Original publication identified
- [ ] Duplicate check completed
- [ ] Copyright status reviewed
- [ ] Recommendation recorded
