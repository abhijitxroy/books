# Bibliographic Verification Tracker

> This file tracks the verification of individual books listed in `MASTER-BOOKS.md`. It is not a bibliography itself but a tool to ensure the accuracy and completeness of bibliographic metadata.

## Purpose

- Verify bibliographic metadata.
- Track research progress.
- Ensure consistency across the repository.
- Record unresolved issues.

## Verification Workflow

1. Verify title.
2. Verify author/editor.
3. Verify publication year.
4. Verify publisher and edition.
5. Verify ISBN (if applicable).
6. Verify library/catalogue records.
7. Verify public-domain status.
8. Review PDF and OCR quality.
9. Update MASTER-BOOKS.md.

## Verification Criteria

- [ ] Title
- [ ] Author / Editor
- [ ] Original language
- [ ] Publisher
- [ ] Place of publication
- [ ] Publication year
- [ ] Edition
- [ ] ISBN (if applicable)
- [ ] OCLC / WorldCat ID (if available)
- [ ] Library catalogue record
- [ ] Archive.org availability
- [ ] Google Books availability
- [ ] National Digital Library of India (NDLI) availability
- [ ] HathiTrust availability
- [ ] Public domain status
- [ ] OCR quality reviewed
